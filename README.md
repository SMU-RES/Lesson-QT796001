# 小型智能交通装置的制作和控制基础（QT796001）

上海海事大学自动化专业课程资料本地归档。课程为创新与创业类选修课，1 学分，授课教师常宝林。

## 课程情况（据修读记录整理）

- 课程分为多个部分：第一节为焊接实验，在电工电子实验中心 207 焊接房焊接纵横交错的焊接网，每个焊点都要焊；第二、三节起制作 LED 时钟，材料由实验室统一提供，仍在 207 焊接，以直立元件为主，焊接难度不高。
- 焊接房内有一定烟味，建议佩戴防烟口罩。
- 后续内容为 Arduino 巡线小车（含基本巡线与避障功能）：程序由学生自行编写，每两周开课一次；平时可到实验室调试测试；最后一节课以地图巡线形式验收小车效果。
- 成绩构成主要为：巡线小车验收 + 课程结题报告（大报告）。
- 该课动手内容较多、趣味性较强，适合对电子制作感兴趣的同学；若仅以刷学分为目的，投入产出比一般。

## 目录结构

- `references/`：课程讲义与参考资料——讲义 PDF、循迹小车与超声波避障资料、项目报告模板，以及环境搭建指南 5 篇 PDF。
- `reports/`：本人课程结题报告（《基于 Arduino 智能小车的视觉巡视、巡线行驶和避障》，章家铭）。
- `content/`：小车控制程序源码（`src.txt`）与环境搭建工具（串口驱动、串口助手、第三方库等）。
