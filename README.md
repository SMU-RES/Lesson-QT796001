# 小型智能交通装置的制作和控制基础（QT796001）

## 课程简介

课程在电工电子实验中心 207 焊接房上课，动手内容比较多，大致分几个阶段：

- **第一节课：焊接练习**。每人焊一块纵横交错的焊接网，交叉点上的每个焊点都要焊上，主要是练手感。
- **第二、三节课：LED 时钟**。材料由实验室统一提供，仍然在 207 焊接，以直立元件为主，难度不大；焊完通电看屏幕显示，就知道自己焊得怎么样。
- **后续内容：Arduino 巡线小车**。小车套件由实验室提供，程序自己写，实现最基本的巡线和避障功能；课程每两周上一次，平时可以随时到实验室做测试；最后一节课按地图巡线验收。

## 资料导航

- **references/**：课程讲义（原 PPT 转为 PDF）、循迹小车与超声波避障资料、项目报告模板（4 份 PDF）。
- **reports/**：课程结题报告《基于 Arduino 智能小车的视觉巡视、巡线行驶和避障》，可参考写法与结构。
- **content/Arduino程序/**：小车程序两个版本——避障版用超声波模块测距避障；巡线版用三路循迹模块沿线行驶。两版共用电机驱动（I2C PWM 芯片）和按键开关部分。
- **content/第三方库/**：编译需要的 Arduino 库（Adafruit BusIO、NeoPixel、PWM Servo Driver、IRremote、TM1650），在 Arduino IDE 中通过“加载库”逐个导入。

## 课程要求与流程要点

### 焊接课注意事项

- 焊接房烟味比较重，建议戴防烟口罩，普通口罩不防烟。
- 焊接内容本身简单，基本都是直立元件，关键是每个焊点焊牢，不要虚焊。

### 巡线小车

- 程序不复杂，主要是电机控制和传感器读数，直接参考 content/Arduino程序/ 里两个 .ino 修改即可。
- 平时可以去实验室跑车调试；最后一节课正式验收，要沿赛道直线走完，不能歪歪扭扭。
- 除验收外还要交一份课程结题报告（大报告），格式可参考 references/ 里的模板和 reports/ 里的报告。

### 成绩与投入

- 成绩主要看两块：小车巡线验收 + 课程结题报告。
- 这门课动手内容多、比较好玩，适合对电子制作感兴趣的同学；如果只为刷学分，性价比一般。

## 使用建议

- **编译下载**：装好依赖库后，打开对应版本的 .ino，直接编译下载到小车即可。
- **硬件说明**：小车为四轮底盘，四个电机由底层驱动芯片经 I2C 控制；避障版接超声波模块（TRIG/ECHO），巡线版接三路循迹模块（A0–A2 模拟口）。

本仓库为课程资料本地归档，供学习参考。
